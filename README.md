# Sparkle Jewellery

Sparkle Jewellery är en e-handelsplattform för smycken.
Kunden kan se produkter, lägga produkter i varukorgen och genomföra ett köp.
Administratören kan lägga till och redigera produkter samt se inkomna ordrar.

## Deployment

Projektet är deployat på AwardSpace och använder en MySQL-databas på servern.
Produktbilderna lagras i Supabase Storage.


## Teknik

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Supabase Storage
- AwardSpace


## Köra projektet lokalt

Projektet kan köras lokalt med XAMPP.

1. Starta Apache och MySQL i XAMPP.
2. Lägg projektmappen i `htdocs`.
3. Importera databasen till phpMyAdmin.
4. Kontrollera att `api/db.php` använder den lokala MySQL-databasen.
5. Öppna projektet via localhost i webbläsaren:

`http://localhost/fsu25d-systemutveckling-uppgift-1-min-egna-e-handel-LynnWigardt/`
